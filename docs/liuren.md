# 大六壬起課

資料:`packages/knowledge/data/liuren.json`;驗證:`packages/knowledge/test/liuren.test.mjs`、`packages/engine/test/liuren.test.mjs`;引擎:`castLiuren`(出生時刻或指定時刻)、`castLiurenKe`(純干支核心)。來源:《六壬大全》十二卷(不著撰人,明刊,四庫全書本,維基文庫)。只錄起課規則同書中課例;課體吉凶斷語未收,本站只列起課結果。

## 步驟

1. **月將**:當令中氣換將(中氣交接時刻起算,精確到分):雨水亥、春分戌、穀雨酉、小滿申、夏至未、大暑午、處暑巳、秋分辰、霜降卯、小雪寅、冬至丑、大寒子;每將有神名(如亥為登明)。
2. **天地盤**:地盤子至亥固定;月將加於占時之上,天盤其餘順推。
3. **四課**:一課下為日干、上為日干寄宮之天盤支;二課下為一課上神、上為其天盤支;三課下為日支、上為其天盤支;四課下為三課上神、上為其天盤支。十干寄宮:甲寅、乙辰、丙戊巳、丁己未、庚申、辛戌、壬亥、癸丑。
4. **三傳**(九宗門,先到先用):伏吟、返吟、八專、賊剋(下賊上先、上剋下次)、比用、涉害、遙剋(蒿矢先、彈射次)、昴星、別責。一般中傳為初傳之上神、末傳為中傳之上神;伏吟、返吟、八專、昴星、別責各有特例。
5. **天乙貴人**:按日干與晝夜取貴人所在支,再按貴人所臨地盤支定順布或逆布,排十二天將落天盤。

## 已定規則

| 項 | 定法 |
|---|---|
| 晝夜 | 占時卯至申為旦(晝貴),酉至寅為夜 |
| 順逆 | 貴人所臨地盤支在亥子丑寅卯辰順布,在巳午未申酉戌逆布 |
| 貴人 | 甲戊庚旦丑夜未;乙己旦子夜申;丙丁旦亥夜酉;辛旦午夜寅;壬癸旦巳夜卯 |
| 涉害 | 由上神加臨之地盤位順數至其本家,逐位計剋數,多者為用;同深取孟、無孟取仲,再同為綴瑕 |
| 日辰 | 同八字日柱;子時換日跟奇門同法;不傳時刻時用出生時刻(有經度按真太陽時) |

## 訂訛

- 月將:書「夏至後日躔鶉」脫「首」字,未將為鶉首;「處暑後日躔鶉首」次名誤,巳將為鶉尾;「大雪後日躔析木」中氣誤,寅將當為小雪後。
- 涉害丁卯日、甲辰日例:「巳」當作「己」(己寄未)。
- 別責丙辰日例:首句「昴星四課不備」,實為別責課。
- 涉害甲午日例:書取「復等」用綴瑕,按孟仲次序應先以見機取辰;初傳同為辰,只子格名異。

## 本站取法(書無明文)

以下於 `liuren.json` 標 `modern`:

- 四課起法:據書中例子反推。
- 晝夜界:卯至申為旦、酉至寅為夜。
- 伏吟有剋、返吟有剋、涉害候選的處理。
- 遙剋有多個神:先比用,比不出再計涉害;蒿矢按上剋下數所剋、彈射按下賊上數剋者,子格仍為蒿矢或彈射。
- 涉害同深而孟有兩個或以上:不再看仲,直接綴瑕(窮舉 8640 課未出現)。
- 伏吟有剋而初傳自刑:以初傳是否等於日上神判斷「用日者」。
