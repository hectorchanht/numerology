# Nicomachus《算術入門》

資料:`packages/knowledge/data/nicomachus.json`;驗證:`packages/knowledge/test/nicomachus.test.mjs`。來源:Nicomachus of Gerasa, *Introduction to Arithmetic*, D'Ooge 英譯(Macmillan 1926,美國公有領域)。頁碼係 1926 年印刷頁。

## 數嘅分類(卷一)

- 偶數:偶偶數 2ⁿ、偶奇數 2 × 奇數、奇偶數 2ᵏ × 奇數(k ≥ 2)。
- 奇數:質數、合數、相對互質。
- 按真因數和:過剩、不足、完全。

## 完全數(p. 209)

由 1 起累加 1, 2, 4, 8…,和係質數就乘最後一項:1+2 = 3 → 6;1+2+4 = 7 → 28;15 唔係質數跳過;31 → 496;127 → 8128。即 Euclid 嘅 2ⁿ⁻¹(2ⁿ − 1)。

作者論點(唔成立):「每個位數級各一個」同「尾數 6、8 交替」。第五個完全數 33,550,336 有 8 位,第五、第六個尾數都係 6。

## 形數(卷二)

k 邊形數 = 由 1 起、公差 k − 2 嘅數列逐項累加。

| 邊 | 數列 |
|---|---|
| 3 | 1, 3, 6, 10, 15, 21, 28, 36, 45, 55 |
| 4 | 1, 4, 9, 16, 25, 36, 49, 64, 81, 100 |
| 5 | 1, 5, 12, 22, 35, 51, 70 |
| 6 | 1, 6, 15, 28, 45, 66 |
| 7 | 1, 7, 18, 34, 55, 81, 112, 148 |

相鄰兩個三角數之和係平方數;三角數加下一個平方數得五角數。立方數 = 連續奇數分組之和:1;3+5;7+9+11…

## 十種比例(卷二 p. 281)

a > b > c:

| # | 例 | 條件 |
|---|---|---|
| 1 算術 | 3, 2, 1 | a − b = b − c |
| 2 幾何 | 4, 2, 1 | a : b = b : c |
| 3 調和 | 6, 4, 3 | (a − b) : (b − c) = a : c |
| 4 相反 | 6, 5, 3 | (a − b) : (b − c) = c : a |
| 5 | 5, 4, 2 | (a − b) : (b − c) = c : b |
| 6 | 6, 4, 1 | (a − b) : (b − c) = b : a |
| 7 | 9, 8, 6 | (a − c) : (b − c) = a : c |
| 8 | 9, 7, 6 | (a − c) : (a − b) = a : c |
| 9 | 7, 6, 4 | (a − c) : (b − c) = b : c |
| 10 | 8, 5, 3 | (a − c) : (a − b) = b : c |

## 最完美比例(p. 284)

6, 8, 9, 12:9 係 6 同 12 嘅算術中項,8 係調和中項,而且 6 : 8 = 9 : 12。音樂上 6:12 八度、6:9 五度、6:8 四度、8:9 全音,同《蒂邁歐篇》(`timaeus.md`)同律呂三分損益一致。
