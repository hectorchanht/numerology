# 河洛理數卷二爻斷、卷三詩訣

資料:`packages/knowledge/data/heluo-shiduan.json`;驗證:`packages/knowledge/test/heluo-shiduan.test.mjs`;查詢:`heluoText(卦名)`。

## 內容

- 卷二(上、下):每卦一段卦註(屬何宮幾世、屬何月、納甲干支,生於該月或納甲者為得時),每爻一段爻斷。爻斷以「此爻是……」起,分「叶者」「不叶者」兩面,再講「歲運逢之」在仕、在士、在庶俗各如何。乾用九、坤用六兩本都無斷語。
- 卷三:每卦總訣,每爻爻訣,一首至五首不等,共 1140 首。部分詩前有小注「陰」「陽」「陽五」「陰五」,書中無解釋,原樣記入 `tag`。

## 版本同整理

- 底本:上海文明書局石印本。卷二喺 `raw_pdf/河洛理數1.pdf` pp. 119–276,卷三喺 `raw_pdf/河洛理數3.pdf` pp. 2–116。
- 校本:GGZBCK405 明刻本。佢卷二下缺 pp. 17–22,即睽初九至解六三,呢段只得文明本。
- MinerU 漏認大量爻訣標題,雙欄排版亦令段落次序錯亂。整理時逐頁對原圖,疑字放大再睇,再用 GGZ 校。
- 只改 OCR 誤認。文明本同 GGZ 有異文時,照錄文明本,記入 `variants`,共 451 條;未能定者記入 `unsure`,共 131 條。
- 句讀:爻斷不加標點。詩每句以「。」收,係本站所加;雜言詩照原印分句。
- 爻名按卦畫改正三處:蹇上六(兩本都印上九)、同人上九(文明本印上六)、巽九三(文明本印九二)。
- 卦註宮世有幾處同京房不合,例如復「坤宮二世」、困「兌宮二世」,照印本保留。

## 用法

- AI 多體系一節附:先天卦卦註;先天、後天元堂爻嘅爻斷同爻訣;當年流年卦爻嘅爻訣。
- 叶定唔叶,書中由元氣、化工、時令等決定,本站未有判定,所以指令要求兩面並列。
- 週期卡唔顯示原文。
