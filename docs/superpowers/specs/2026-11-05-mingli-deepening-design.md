## A. 八字加深

全部走主盤路徑:擴 `BaziChart` / `FortuneAnalysis`(`packages/engine/src/types.ts`、`fortune.ts`),
AI 經 `buildContextPack` / `renderFortune`(`packages/ai/src/context.ts`),UI 入 `BaziDetail.tsx`、`FortuneSections.tsx`。

1. **干支關係**(新檔 `packages/engine/src/relations.ts`):天干五合、天干相沖;地支六合、三合(含半合)、三會、六沖、六害、三刑(含自刑)、相破。
   - 原局四柱之間全部列出(哪兩柱 / 三柱、類型、化神五行如適用)。
   - 大運、流年各對原局列出關係;標「歲運並臨」「天剋地沖」。
   - 規則表放 `packages/knowledge`(新 JSON,cite《三命通會》卷二相應篇名:支元六合、三合、六害、三刑、沖擊)。
2. **胎元、胎息、命宮、身宮**:用 lunar-javascript `getTaiYuan` / `getTaiXi` / `getMingGong` / `getShenGong` 及納音;補 `lunar-javascript.d.ts` 類型。附《三命通會》「亦多有不驗」嘅四庫提要註,UI 可展開。
3. **小運、流月**:`DaYun.getXiaoYun`、`LiuNian.getLiuYue`;流月只出當前流年(及查詢年)十二個月,每月十神 + 對原局關係。
4. **格局**(新檔 `packages/engine/src/geju.ts`):《子平真詮》月令取格——月支本氣透干取本氣,否則看透出之中氣 / 餘氣;八正格(正官、七殺、正財、偏財、正印、偏印、食神、傷官)+ 建祿、月劫(陽刃)。
   - 取格步驟逐步列出;多個透干時按《子平真詮》次序並列「主格 / 兼格」,唔強行單一。
   - 外格(從格、化氣格等)只沿用 `fuyi.possibleCong` 偵測標示,不判定。
   - tier modern 標「本站按《子平真詮》月令取格簡化,不含成敗救應」。
5. **神煞補漏**(用戶確認要做):天德、月德、紅鸞、天喜、學堂,入 `shensha.ts`,cite《三命通會》。

## B. 紫微加深

1. **運限盤**:用 iztro `astro.horoscope()` 出大限、小限、流年、流月、流日:
   - 每層:命宮落本命邊宮、十二宮疊宮(`palaceNames`)、該層四化落宮、運限流耀(流祿、流羊、流陀、流昌、流曲、流魁、流鉞、流馬等,`stars`)。
   - 流日預設今日,可選日期;流時不做。
2. **斗君**:iztro 2.5.8 流月起法(流年宮 − 生月 + 生時 + 流月,含閏月)同《全書》條訣一致;直接用,加測試鎖定。
3. **三方四正**:UI 已可點任意宮 highlight;補 engine `computeSanFangSiZheng` 任意宮輸出同 AI facts。
4. **小限**:現已傳入 `ages` 但冇顯示、AI 冇收,補上。
5. **長生 / 博士 / 將前 / 歲前**:已顯示,補入 AI facts。
6. **飛星派(流派說法)**:宮干飛化(`fliesTo` / `mutagedPlaces`)、自化(`selfMutaged`)、祿忌交馳偵測(iztro 冇呢個 API,自寫)。
   - 獨立區塊,tier modern,UI 標「飛星派說法(二十世紀),非《紫微斗數全書》內容」,預設摺埋。
   - AI facts 同一標籤;prompt 指示不可以呢部份作主要判斷。
7. **四化疊化**:生年 / 大限 / 流年(/ 流月)四化落同一星或同一宮時標示(祿疊祿、忌疊忌、祿忌同宮)。
8. **紫微格局識別**(新檔 `packages/engine/src/ziwei-geju.ts` + knowledge JSON):只收《紫微斗數全書》(含〈骨髓賦〉〈太微賦〉)有載嘅格局,例如紫府同宮、機月同梁、殺破狼、府相朝垣、日月並明、君臣慶會、火貪 / 鈴貪、馬頭帶箭、命無正曜。
   - 每格 4 欄:星曜組合、成格宮位、成格條件、吉 / 凶;cite 篇名。逐格列出命中步驟。
   - 書中搵唔到原文嘅格局唔收。
9. **星曜條目**(knowledge,補 `mingli-glossary`):十四主星每粒加五行、斗位(北斗 / 南斗 / 中天)、化氣、主司;文字由《全書》原文摘短句 + 本站白話,不抄任何網站。逐宮解讀、雙星組合留待後期。
10. 流派設定:保持 iztro `algorithm: "default"`;唔開放中州派切換(YAGNI)。
