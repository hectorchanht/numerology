## 一、太玄經 729 贊

- 出處:揚雄《太玄經》(約 4 BCE–AD 2),原文公有領域(ctext.org / 維基文庫)。tier `classical`。
- 結構:81 首 × 9 贊 = 729 贊;每贊當半日(一晝或一夜),729 贊 = 364.5 日;另以「踦」「嬴」二贊補足歲餘(合 365.25 日)。
- 起點:**冬至**(以 lunar-javascript 取出生前最近一個冬至的精確時刻)。首一為「中」。
- 算法:`elapsed = 出生時刻(真太陽時) − 冬至時刻`,以半日為單位取整 → `index`(0 起)。`index < 729` 時:首 = ⌊index / 9⌋ + 1,贊 = index mod 9 + 1;`index ≥ 729` 時落入踦 / 嬴(依次)。計算步驟全部輸出。
- **晝夜判定的流派分歧**:半日的切分點(以子夜 / 正午切,或以日出 / 日落切)各家不一。本站採「子夜–正午」等分法,並在步驟中明說(原則 8)。
- 資料:`packages/knowledge/data/taixuan.json`——81 首首名(繁體原字)、首序、各首所配卦氣節候(若原文有)、cite(篇章 + ctext / 維基文庫 URL,須實際抓取核對,不得編造 URL)。另加 `.data.ts` 內聯 + deepEqual 測試。
- 九贊之位(一至九)在《太玄》中有「思、福、禍」三分等說;只收原文明載者,未載者不收。

## 二、瑪雅曆

- 出處:古典期瑪雅曆法;相關常數採學界通用 **GMT 對應(584283)**。tier `classical`(曆法)/ `scholarly`(對應常數為現代學者推定,須標明)。
- 算法(皆由出生民用日期的儒略日數 JDN 計):
  - 長紀曆:`days = JDN − 584283` → baktun.katun.tun.winal.kin(20/18/20/20 進位)。
  - Tzolk'in:數字 1–13 與 20 日名;錨點 **2012-12-21 = 13.0.0.0.0 = 4 Ajaw 3 K'ank'in**。
  - Haab:18 個 20 日月 + Wayeb 5 日。
- 日名 / 月名:用現代通行拼寫(Ajaw、K'ank'in 等),另附舊拼寫別名;cite 指向學術來源(如 Thompson 1950 或 FAMSI 公開資料),只寫事實。
- **Dreamspell(Argüelles 1987)不計算**,只在說明中標 `modern`:「與傳統瑪雅曆日期不同步,屬現代發明」。避免用戶把兩者混淆。
- **相關常數分歧**:584283(GMT)與 584285 相差 2 日,屬學界爭議;步驟中明說採 584283(原則 8)。

## 四、AI

- `crosssystem` 一節的事實區塊加入太玄與瑪雅結果(值、步驟摘要、tier、cite);仍不入五行比對。

## 五、學院科學專區

- 新頁 `/science`(導覽「學院」分組下):
  1. 科學筆記列表:來自 `science-notes.json`,三語、cite、待校對徽章。
  2. **基率模擬器**:用戶選體系數 k(2–6)與類別數 m(預設 5,即五行),按「模擬」以固定種子的偽亂數跑 N = 10,000 次,畫出「至少 j 個體系與錨點相同」的分佈長條圖,並列出解析解(二項分佈)對照。同一輸入同一輸出(原則 13)。
  3. 一段文字說明 look-elsewhere effect,引用 `look-elsewhere` 條目。
- 模擬與解析解為純函數,有測試(解析解 j≥1 時 = 1 − (1 − 1/m)^k)。

## 測試要點

- 太玄:冬至當刻 → 首 1 贊 1;冬至後 12 小時 → 首 1 贊 2;第 729 個半日落入踦;真太陽時跨日情況。
- 瑪雅:2012-12-21 → 13.0.0.0.0、4 Ajaw、3 K'ank'in;另取一個學術資料核對過的日期作第二錨點。
- 模擬器:固定種子輸出可重現;k=4、m=5 時「至少一個相同」解析解 = 1 − 0.8⁴ = 0.5904。
