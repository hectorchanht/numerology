## 一、扶抑喜忌引擎(`packages/engine/src/fuyi.ts`)

- 出處:子平法扶抑論(《子平真詮》《滴天髓》);**評分權重為本站規則**,tier `modern`,並在步驟與 UI 中寫明「本站簡化評分,非古籍原文」(原則 8、11)。
- 評分(全部可展開步驟):
  - 得令:月支本氣五行與日主關係——同我或生我 +3,否則 −3。
  - 得地:四柱地支藏干(本氣 1.0、中氣 0.5、餘氣 0.3)中同我或生我者加分,剋洩耗者減分(日支計入,月支已計得令則只計中餘氣)。
  - 得勢:年、月、時三天干,同我或生我各 +1,剋洩耗各 −1。
  - 總分 > +1.5 → 身強;< −1.5 → 身弱;其間 → 中和。
- 喜忌:身弱 → 喜用 = 印、比劫五行;忌 = 官殺、食傷、財五行。身強 → 喜用 = 食傷、財、官殺;忌 = 印、比劫。中和 → 不定喜忌,標「中和,以調候為參」。
- 從格偵測:身弱且總分 ≤ −6,或身強且總分 ≥ +6 → 標 `possibleCong: true`,喜忌照算但 UI / AI 明說「可能從格,扶抑結論僅供參考」。
- 輸出:`{ score, verdict: "strong"|"weak"|"neutral", favorable: Wuxing5[], unfavorable: Wuxing5[], possibleCong, steps, tier: "modern", cite }`。
- 測試以手算樣例為準(至少三例:明顯身強、明顯身弱、中和),數值寫在測試註解中。
