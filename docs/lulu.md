# 律呂三分損益

資料:`packages/knowledge/data/lulu.json`;驗證:`packages/knowledge/test/lulu.test.mjs`。來源:《管子·地員》、《呂氏春秋·音律》、《淮南子·天文訓》(公有領域,據維基文庫)。

## 規則

- 三分損一:律管長度 ×2/3,叫「下生」,音高升五度。
- 三分益一:律管長度 ×4/3,叫「上生」,音低降四度。
- 由黃鐘 81 起輪流損益,生出十二律。淮南子話「置一而十一三之」得 3¹¹ = 177147,即十二律全部係整數所需嘅最小黃鐘數。

## 管子五音

1 × 3⁴ = 81 為宮,先益後損:

| 音 | 數 | 由上一音 |
|---|---|---|
| 宮 | 81 | 起點 |
| 徵 | 108 | ×4/3 |
| 商 | 72 | ×2/3 |
| 羽 | 96 | ×4/3 |
| 角 | 64 | ×2/3 |

管子先「益」,所以徵 108、羽 96 比宮低;淮南子同後世由黃鐘先「損」。

## test 驗證咗乜

- 管子五音逐步重算。
- 淮南子律數同精確值相差少過 1:應鐘取 42(精確 42⅔)、夾鐘取 68(精確 67.42),所以唔係一律四捨五入。
- 仲呂再損一得唔返清黃鐘,差一個 Pythagorean comma 3¹²/2¹⁹ ≈ 1.0136。
- 呂氏上下兩組同淮南子嘅上生/下生,只係蕤賓一步唔同:呂氏將蕤賓列上組(下生大呂),淮南子寫蕤賓上生大呂。
- 兩書嘅律同月份對應完全一致。
