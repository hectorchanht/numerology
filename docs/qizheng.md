# 七政四餘

## 概述
七政四餘用二十八宿記各曜位置:七政(日、月、水、金、火、木、土)取星曆回歸黃經,四餘(羅睺、計都、月孛、紫氣)用公式推算。引擎 `castQizheng` 輸出每曜黃經、古宿度同現代宿度,週期卡列表、AI 多體系事實引用。只列位置,唔作吉凶斷語(《星學大成》斷語未入庫)。

## 已定規則
| 項 | 定法 |
|---|---|
| 七政 | 黃經取 `castEphemeris`(東八區鐘面、未計夏令時) |
| 羅睺 / 計都 | 平均升交點 Ω = 125.04452° − 1934.136261°·T 為羅睺,計都 = 羅睺 + 180° |
| 月孛 | 平均遠地點 = 平均近地點 + 180° |
| 紫氣 | 《推步捷例》平行 126.7207777″/日,由乾隆甲子元起算,換算為回歸黃經 |
| 現代宿度 | 距星 J2000 黃經加歲差(50.29″/年)推到出生日;宿 = 黃經 ≥ 該宿距星而 < 下一宿距星 |
| 古宿度 | 《六壬大全》卷十一宿度表,合周天 365 度;錨定角宿距星,現代度 × 365 / 360 化古度後累計 |

## 分歧同限制
- **羅計對調**:《張果星宗》《清史稿》以升交為羅睺、降交為計都;《推步捷例》以正交為計都,剛好相反。本站取前者,輸出 `variants` 同 UI、AI 文字均標明。
- **紫氣**:崇禎曆書、清史稿均言無實象,只係《推步捷例》嘅流派公式,標 `tier: modern`。《星學大成》卷十九以 28 年(10228 日)為周期,同推步捷例相差不足 1%,作對校。
- **古宿度來源**:《六壬大全》卷十一(公版,四庫本),各宿初度概取 1 度,觜附參,故古宿度內參宿範圍包觜;《星學大成》度歌讀法記在知識表 `variants`。
- **參宿距星**:取 ζ Ori(參宿一,清代儀象考成以後觜前參後之取法);古代以 δ Ori 為距星時觜在參後。
- **歲差上限**:全部距星當同速(一般歲差 50.29″/年),忽略黃緯同黃道移動項,1900–2100 年誤差約 0.01° 級;要更準可改用 astronomy-engine 歲差旋轉。
