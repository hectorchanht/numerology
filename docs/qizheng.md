# 七政四餘

## 概述
七政四餘用二十八宿記各曜位置:七政(日、月、水、金、火、木、土)取星曆回歸黃經,四餘(羅睺、計都、月孛、紫氣)用公式推算。引擎 `castQizheng` 輸出每曜黃經、古宿度、現代宿度、所落宮(地支 + 十二次名)同十二宮名,另出命宮,週期卡列表、AI 多體系事實引用。只列位置,唔作吉凶斷語(《星學大成》斷語未入庫)。

## 已定規則
| 項 | 定法 |
|---|---|
| 七政 | 黃經取 `castEphemeris`(東八區鐘面、未計夏令時) |
| 羅睺 / 計都 | 平均升交點 Ω = 125.04452° − 1934.136261°·T 為羅睺,計都 = 羅睺 + 180° |
| 月孛 | 平均遠地點 = 平均近地點 + 180° |
| 紫氣 | 《推步捷例》平行 126.7207777″/日,由乾隆甲子元起算,換算為回歸黃經 |
| 現代宿度 | 距星 J2000 黃經加歲差(50.29″/年)推到出生日;宿 = 黃經 ≥ 該宿距星而 < 下一宿距星 |
| 古宿度 | 《六壬大全》卷十一宿度表,合周天 365 度;錨定角宿距星,現代度 × 365 / 360 化古度後累計 |
| 十二宮(過宮) | 《星學大成》卷一〈約二十八宿過宫度數歌〉:「氐一過卯尾三寅」…「張十四巳軫九辰」十二界,套用喺古宿度上;「某宿 N 度」讀作宿內古度 ≥ N 入下一宮(本站讀法)。宮闊 28–33 古度,合 365 |
| 十二次名 | 只取《晉書》卷十一〈天文志上·十二次度數〉次名同辰之對應(亥次晉書作「諏訾」,用通行寫法娵訾);晉書次界度數唔用 |
| 命宮 | 《張果星宗》卷八「以生时加在太阳度上」、《星學大成》卷四「以太陽數至卯為命」:命宮支序 = 日宮 + 3 − 時支(子 0 … 亥 11);時支用鐘面時(東八區),未計真太陽時,只定到宮,唔計安命度 |
| 十二宮名 | 《星學大成》卷四「一命宫二財帛…十二相貌」;由命宮逆地支排(《張果星宗》卷二例:寅上安命、巳為官祿) |

## 分歧同限制
- **過宮度**:《張果星宗》卷一〈度数所在〉斗、女、張、軫四界(「斗四」「女二」「张十五」「轸十」)比《星學大成》各晚 1 度,記入知識表 `gong.variants`;其餘八界相同。
- **羅計對調**:康熙《御製曆象考成》上編卷五〈太隂各種行度〉明定方向:「其自黄道南過黄道北之㸃名曰正交」(即升交),小注「正交曰羅㬋中交曰計都」;《張果星宗》《清史稿》同。《推步捷例》(1861)以正交為計都,剛好相反,疑沿乾隆九年「更定羅睺、計都名目」(《清史稿》卷45)。本站從曆象考成,輸出 `variants` 同 UI、AI 文字均標明推步捷例對調。
- **紫氣**:崇禎曆書、清史稿均言無實象,只係《推步捷例》嘅流派公式,標 `tier: modern`。《星學大成》卷十九以 28 年(10228 日)為周期,同推步捷例相差不足 1%,作對校。
- **古宿度來源**:《六壬大全》卷十一(公版,四庫本),各宿初度概取 1 度,觜附參,故古宿度內參宿範圍包觜;《星學大成》度歌讀法記在知識表 `variants`。
- **古宿度再查(2026-11-05)**:spec 原定以《星學大成》/《張果星宗》宿度表為主,但兩書公版錄文都湊唔出完整 28 宿表:
  - 《星學大成》卷一〈約二十八宿度數歌〉係歌訣,壁(「三五」)、箕、牛、虛(「無十度」)四宿讀唔定,鬼(「一増雙」)、柳(「二七」)亦有歧讀;確定嘅 24 宿合 325.5 度,同卷「周天都計三百六十五度二十分五十秒」只餘一條方程,解唔出四個未知。歌末自言「以上度數特其槩耳其詳具於三辰通載」,而《三辰通載》詳表未見公版(《張果星宗》卷十二〈三辰通載〉只存序)。
  - 《張果星宗》卷一〈度数所属〉錄文錯亂(如「房日兔五属六宿」「斗木獬、牛金牛亦六十数」),總和唔合 365;卷三「钦天监校正授时过宫度图」缺圖。
  - ctext 全文檢索對自動請求冇結果(並禁止批量下載),維基文庫只有四庫本一個版本。
  - 結論:維持《六壬大全》卷十一為主表,冇加新嘅可選宿度表。
- **參宿距星**:取 ζ Ori(參宿一,清代儀象考成以後觜前參後之取法);古代以 δ Ori 為距星時觜在參後。
- **歲差上限**:全部距星當同速(一般歲差 50.29″/年),忽略黃緯同黃道移動項,1900–2100 年誤差約 0.01° 級;要更準可改用 astronomy-engine 歲差旋轉。
